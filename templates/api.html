API

Alle gegevens van Prijsspoor zijn als JSON beschikbaar, zonder sleutel. Bedragen zijn in euro, tijdstippen in UTC (ISO 8601). Wees redelijk met het aantal verzoeken: de prijzen veranderen hoogstens om de zes uur.

Prijs opvragen met een Collect&Go-link

GET {{ base }}/api/v1/price?url=<link naar een productpagina>

Geef de volledige link van een productpagina op collectandgo.be mee (Nederlands of Frans, met of zonder https://). Codeer de link als querystring-parameter.

curl -G '{{ base }}/api/v1/price' --data-urlencode 'url={{ example_url }}'

Antwoord (ingekort):

{
  "product": {
    "id": "{{ example_id }}",
    "article_number": "28856",
    "name": "BONI walnootpitten 200g",
    "brand": "Boni",
    "content": "200g",
    "url": "https://www.collectandgo.be/nl/assortiment/…",
    "is_available": true,
    "promotions": []
  },
  "price": {
    "currency": "EUR",
    "price": 3.19,
    "unit_price": 15.95,
    "unit": "kg",
    "offer": { "price": 3.06, "min_quantity": 3, "unit_price": 15.3 },
    "reference_price": null,
    "is_red_price": false
  },
  "last_updated_at": "2026-11-15T18:00:04Z",
  "last_changed_at": "2026-11-02T06:00:03Z",
  "previous_price": 3.29,
  "tracked_since": "2026-10-20T12:00:01Z",
  "history_url": "{{ base }}/api/v1/products/{{ example_id }}/history",
  "page_url": "{{ base }}/product/{{ example_id }}"
}
last_updated_at
Wanneer we deze prijs voor het laatst op Collect&Go zagen.
last_changed_at
Wanneer de huidige prijs voor het eerst verscheen, dus het moment van de laatste prijswijziging. Is deze gelijk aan tracked_since, dan veranderde de prijs niet sinds we het product volgen.
previous_price
De prijs vóór de laatste wijziging, of null.
offer
Hoeveelheidskorting: de stukprijs als je minstens min_quantity stuks koopt.

Foutcodes: 400 als de link geen Collect&Go-productpagina is, 404 als er op die link geen product staat, 502 als Collect&Go niet antwoordt. De body is dan {"error": "…", "status": 404}.

Producten zoeken

GET {{ base }}/api/v1/products?q=koffie&page=1&per_page=24&sort=prijs&available=true

sort is relevantie (standaard), prijs, prijs_desc, naam of gewijzigd. per_page is maximaal 100.

Eén product

GET {{ base }}/api/v1/products/{id}

id is het Collect&Go-product-ID of het artikelnummer. Het antwoord heeft dezelfde vorm als hierboven.

Prijsgeschiedenis

GET {{ base }}/api/v1/products/{id}/history

Geeft elke prijsperiode, oudste eerst: {"price", "unit_price", "offer_price", "offer_min_quantity", "reference_price", "is_red_price", "from", "until"}. from is de eerste en until de laatste waarneming van die prijs.

Recente wijzigingen

GET {{ base }}/api/v1/changes?days=7&direction=down&limit=50

direction is down, up of weggelaten voor alle wijzigingen.

Status

GET {{ base }}/api/v1/status

Aantal producten en prijzen en de laatste ophaalrondes.
